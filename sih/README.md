# AI Real-Time Noise Cancellation PrototypeThis project is a real-time speech enhancement prototype that captures microphone audio, processes it with the RNNoise backend, and plays the enhanced output through a selected audio device. The current runtime path uses the real RNNoise engine from `noise_suppression/rnnoise_engine.py`; the CNN file under `models/` is present for reference and development, but the GUI currently runs through RNNoise rather than the CNN model.## What the project does- Captures live microphone audio from system devices.- Uses the real RNNoise backend for noise suppression.- Works with audio device selection on Windows and Linux.- Allows playback through a selected output device.- Stores recorded noisy audio as WAV files for later review.## Current runtime architecture- Input: connected microphone or headset input device- Processing: `RNNoiseEngine` using the `pyrnnoise` native library- Output: selected playback device- Sample rate: 48 kHz- Frame size: 480 samples## Windows usage```bashpython -m pip install -r requirements.txtpython main.py```## Raspberry Pi 5 installationRun the following on the Raspberry Pi 5 with Raspberry Pi OS:```bashgit clone <repo-url>cd <repo-folder>git checkout raspberry-pipython3 -m venv .venvsource .venv/bin/activatepython -m pip install --upgrade pippython -m pip install -r requirements.txt```### Required Linux audio packagesDepending on the OS image, install the system audio packages needed for PortAudio / ALSA / PipeWire support:```bashsudo apt updatesudo apt install -y portaudio19-dev alsa-utils pipewire pipewire-pulse wireplumber```If the system uses PipeWire, do not restart or disable it; the app should work with the available audio devices exposed through the Linux audio stack.## Raspberry Pi usage1. Connect the USB microphone or USB audio interface.2. Connect the speaker or Bluetooth headset if desired.3. Check whether the device is visible:```bashpython - <<'PY'import sounddevice as sdprint(sd.query_devices())PY```4. Launch the app:```bashchmod +x open_app_pi.sh./open_app_pi.sh```or:```bashsource .venv/bin/activateexport PYTHONPATH="$PWD"python main.py```## Device troubleshootingIf the app reports that no microphone or output device is available:```bashpython - <<'PY'import sounddevice as sdprint('default device:', sd.default.device)print('devices:', sd.query_devices())PY```Check the following:- USB microphone is plugged in and recognized by the OS.- Bluetooth headset is connected and exposed through PipeWire.- ALSA/PortAudio is installed and working.- The selected device index is valid for the current hardware.## RNNoise / model notesThis project does not currently rely on the CNN model in the main GUI workflow. The real processing path is RNNoise through `pyrnnoise` and is the path that should be preserved on Raspberry Pi.The existing `models/cnn_mask_model.pt` file should not be retrained or removed.## Notes- The app defaults to 48 kHz mono input and RNNoise block processing.- The project should remain as compatible as possible with the existing Windows app.- Raspberry Pi testing is hardware-dependent and must be done on the actual device.
